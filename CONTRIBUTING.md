# Adding and correcting notes

[Repository home](README.md) · [Topic template](templates/topic-template.md)

Keep these notes useful to someone meeting the subject for the first time.

## Add a topic

1. Create or select the subject folder and update its README learning path.
2. Add a numbered Markdown lesson in `notes/` using the topic template.
3. Define symbols, units, geometry, sign conventions, and assumptions before using them.
4. Include at least one fully worked example with a meaningful check.
5. Add original practice problems and separate worked answers in `practice/`.
6. Check arithmetic independently, verify relative links, and preview math/tables on GitHub.
7. Update the subject index and roadmap to reflect what actually exists.

## Correct an error

In an issue or pull request, include the file, example/problem number, the incorrect step, the proposed correction, and a check supporting it. Recheck any answer or formula sheet affected by the correction.

Use original explanations and exercises. If adapting a source, identify it and follow its license. Do not upload copyrighted textbook pages, answer manuals, private course material, or personal academic records without appropriate authorization.

These are independent study notes. Claims about official prerequisites, transfer credit, course policies, or degree requirements need current official sources and belong in a clearly separate document; do not infer them from the study sequence.
