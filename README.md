## How to study

1. Read one lesson and sketch every described system on paper.
2. Cover the solution and attempt its worked example yourself.
3. Solve the matching [practice problems](statics/practice/problems.md) before opening the answers.
4. Record whether each error came from the diagram, geometry, signs, units, or algebra. Redo the problem from a blank page.

Reading a solution is not the same as being able to produce one. Advance when you can set up an unfamiliar problem without copying.

## Repository conventions

- SI units unless stated otherwise; angles in degrees in numerical examples.
- GitHub math notation is used for equations. If a preview does not render it, view the file on GitHub.
- Each subject gets its own folder, numbered lessons, and a practice folder.
- New lessons can use the [topic template](templates/topic-template.md).
- Report corrections with the file, equation/problem number, and corrected reasoning; see [contribution guidance](CONTRIBUTING.md).
