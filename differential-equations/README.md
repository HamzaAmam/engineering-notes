# Differential Equations — planned

[Repository home](../README.md) · [Roadmap](../ROADMAP.md)

This folder reserves space for future lessons. **No Differential Equations lessons or practice solutions are published here yet.** The list below is a proposed independent study sequence, not official course coverage or prerequisites.

1. Functions, derivatives, integrals, and initial conditions.
2. Slope fields, equilibrium solutions, and stability.
3. Separable first-order equations.
4. First-order linear equations and integrating factors.
5. Second-order constant-coefficient equations.
6. Mechanical applications such as mass–spring–damper models.

Future structure: `notes/` for numbered lessons and `practice/` for problems and separate worked answers. Use the [topic template](../templates/topic-template.md) when adding material.
